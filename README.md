# SmartFarm AI

Климат, су, жер және бюджетке сүйене отырып, егістікті оңтайлы жоспарлауға арналған веб-платформа.
Математикалық модельдеу (сызықтық программалау, симплекс әдісі), AI-талдау және 3D визуализацияны біріктіреді.

## Мүмкіндіктер

- **3D ферма** (Three.js, low-poly): егістік телімдері, трактор, су каналы, тоған, үй, силос, жел диірмені, ағаштар, бұлттар
- **Ресурстар**: жер (га), су (м³), бюджет (₸), әртараптандыру шектеуі — slider + number input
- **Дақылдар**: бидай, жүгері, күріш, күнбағыс — барлық параметрлері өзгертіледі, модельден алып тастауға болады
- **Климат**: құрғақ / қалыпты / жаңбырлы жыл — су қоры, су қажеттілігі мен өнімділік түзетіледі, 3D сахна өзгереді
- **AI климат болжамы**: аймақ бойынша сценарий ықтималдықтары
- **Математикалық модель**: мақсаттық функция мен шектеулер нақты сандармен автоматты құрылады
- **Симплекс әдісі**: кестелік симплекс, итерациялар журналы (кіретін/шығатын айнымалы, базис, Z), көлеңкелі бағалар
- **Нәтиже**: KPI, гектар бойынша бөлу, ресурс қолданылуы, интерактивті 3D карта (hover → телім ақпараты)
- **Аналитика**: doughnut және bar диаграммалар (Chart.js)
- **AI ұсынысы**: шешім, көлеңкелі бағалар және сезімталдық сценарийлері бойынша қорытынды, сұрақ-жауап
- **Сценарийлерді салыстыру**: 3 климат бойынша пайда, су, дақыл үлестері, 3D картада көру

## Математикалық модель

```
max Z = p₁x₁ + p₂x₂ + p₃x₃ + p₄x₄

x₁ + x₂ + x₃ + x₄            ≤ L      (жер)
w₁x₁ + w₂x₂ + w₃x₃ + w₄x₄    ≤ W·kᵥ   (су, климатпен түзетілген)
c₁x₁ + c₂x₂ + c₃x₃ + c₄x₄    ≤ B      (бюджет)
xᵢ                           ≤ s·L    (әртараптандыру)
xᵢ ≥ 0
```

`pᵢ = өнімділік × аймақ коэф. × климат коэф. × баға − шығын`

## Технологиялар

- Vite + vanilla JavaScript
- Three.js (3D), Chart.js (графиктер)
- Өзіндік симплекс-солвер (`src/simplex.js`)

## Іске қосу

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Vercel-ге орналастыру

1. Репозиторийді GitHub-қа жүктеңіз.
2. [vercel.com/new](https://vercel.com/new) → репозиторийді импорттаңыз.
3. Framework автоматты анықталады (**Vite**), build: `npm run build`, output: `dist`. **Deploy** басыңыз.
